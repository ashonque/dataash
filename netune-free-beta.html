What Netune does

Most warehouse tools start from a model somebody has already drawn. Netune starts from the database. It connects to SQL Server, profiles every table it is allowed to read — row counts, keys, how values change over time, which columns look like measures and which like attributes — and classifies each table as a fact, a dimension, a bridge or none of those.

Then it scores eight modelling methodologies against what it measured — Kimball, Inmon, Data Vault 2.0, Medallion, Galaxy, One Big Table, Anchor Modeling and Activity Schema — and shows the evidence for each rather than a verdict. You choose one, answer the two questions only a person can answer (the grain of each fact, and how much history each dimension keeps), and Netune draws the target design on a canvas you can edit: rename, retype, add and delete columns, choose where each is read from. Every edit is checked against what the load would do with it.

The output is T-SQL you can read before running: the CREATE TABLE script for the whole design, with keys, indexes and the descriptions you agreed to. The staging layer can be created and filled from inside Netune, in a database you name — never the one it read from.

Nothing leaves your machine. Netune is a local program that opens in your browser. It has no account, no telemetry and no service behind it; the only thing it ever fetches is a language model, and only when you ask it to. The optional model runs locally too, and it never decides any part of the design — it explains, suggests readable names and answers questions about what is on screen.

What you need

  • Windows 10 or 11, 64-bit. Netune runs on your PC and opens in whichever browser you use. Nothing is installed; unzipping is the whole setup.
  • A SQL Server you can read. Any edition from 2016 on, Express included, or Azure SQL. Netune needs read access to the database it profiles, and write access only to whichever other database you choose to stage into.
  • The Microsoft ODBC Driver for SQL Server (17 or 18). Most machines that talk to SQL Server already have it; if yours does not, Netune says so on the first screen and links to it.
  • About 8 GB of memory to be comfortable. The language model is optional and adds 1–5 GB depending on which you pick; Netune measures your machine before offering one.

How to run it

  1. Download the zip above and unzip it anywhere — your Documents folder, a USB stick, wherever. It leaves nothing else on the machine.
  2. Double-click Start Netune.cmd. A small window opens, Netune picks a free port, and your browser opens on it. Leave that window open while you work; closing it stops Netune. Windows may show a SmartScreen notice the first time, because the beta is not yet code-signed — choose More info, then Run anyway. The checksum above is how you know the file is ours.
  3. Type your server name and sign in. Windows login, a SQL login or Microsoft Entra — then List tables, tick the ones you care about, and Analyze.
  4. Read the structural profile, choose a methodology, answer the grain and history questions, and press Build design. Right-click any card to edit it.
  5. Generate SQL, read it, and — if you want staging built — open STG Deploy, name a target database, preview, and confirm.
  6. Optionally, double-click Add desktop shortcut.cmd once for a Netune icon on your desktop, and open the Model panel to fetch a language model if you want the chat and readable names.

    The small print

    The free edition is free to use, including at work. The licence travels in the zip as app\LICENSE.txt, together with app\THIRD-PARTY.md, which lists the software Netune is built on and the terms of each language model it suggests. Language models are not part of Netune: when you ask for one, it is downloaded from its publisher, checked against the publisher's own hash, and licensed to you by its author under terms Netune shows you first. Netune is provided as is; review what it generates before you run it anywhere that matters, and keep backups — the same advice as for any tool that writes SQL.

    Questions people ask first

    Is it really free, or a trial?

    Free. There is no time limit, no account and no key. The free edition simply leaves four features to the full one, and says so inside the program rather than expiring on you.

    Why does it open in a browser if it runs locally?

    Because a browser is the best canvas there is, and it is already on your machine. Netune serves its page to your own computer only, refuses requests from any other website, and stops when you close its window.

    Can it damage my source database?

    It only reads the database it profiles. Every write goes to a database you name, Netune refuses to name the source as a target, and everything that writes shows you a preview and waits for a second confirmation.

    Does it need a GPU for the language model?

    No. The beta runs the model on the processor. It is slower than a GPU, and it works on every machine. Everything except the chat and the readable names works with no model at all.

    Will it work with PostgreSQL, Oracle or Snowflake?

    Not yet. The beta is SQL Server only, on Windows only. Which comes next depends partly on who asks.

    How do I get the full edition?

    Ask for early access on the home page. The full edition is the same program with the load procedures, the warehouse deploy, the landing zone and schedules turned on.
